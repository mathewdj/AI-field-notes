# Principles
- Enduring capabilities work over new technology
- Business leaders need to combine domain knowledge with AI techniques
- AI needs data - ongoing architectural investment
- Re-learn as your business depends on it
- No company has become 10x more efficient bu individuals have become 10x efficient

# Ramp Journey
- Created config as code for AI configuration
- Problem: Setting up MCP servers, skills, etc was time consuming & low sharing was present
- Solution: Glass - A platform where ai is configured on day 1
- See blog post on Ramp

# Glass principles
- Don't limit anyones upside
	- default for non-tech users is to simplify
	- Power users thrive on multi window workflows, scheduled automations & reusable skills
- Don't limit users to archetypes: eg business users should have access to Claude code
- "One person's breakthrough should be everyone's baseline"
	- The biggest failure mode is not sharing a breakthrough
- The product is the enablement

# Structure
- Everything about Glass gets configured on day 1
- Sensei app recommends skills based on role
- Daily synthesis & refinement skill that builds context from previous day's stack events
- Managing context is most valuable
- Every element in Glass is a lesson. Glass shows users good examples of how to write a good skill or prompt
