Rule 1 - Prompt skills over claude - repetitive tasks should be turned into skills. 

Rule 2 - Skills are more than prompts - layer 1 description, layer 2 instructions, layer 3 tools it has access to (most leverage). 

Rule 3 - build composable tools not custom skills. Multiple skills can work together. If a specialised skill breaks you know where to fix it. Pattern 1 - sometimes claude will rewrite the same script multiple times. Therefore have the script added to a skill. Cheaper faster and more reliable. 

Rule 4 - their prompts get faster every session. Sharpen skills each session. If a skill output is wonky, then update the skill to cover that edge case. Use chat history to improve the skills
